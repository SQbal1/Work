# Ride X - Claude Context

## Project Overview

Ride X is a premium private transportation company based in Jeddah, Saudi Arabia.

The website is intended to present Ride X as a trustworthy, professional, premium transportation provider for residents, visitors, families, business travelers, and corporate clients.

The website is not intended to look like:

* A startup landing page
* A SaaS dashboard
* A crypto project
* A gaming website
* A technology demo

The website should feel closer to:

* Executive chauffeur companies
* Luxury airport transfer services
* Premium hospitality transportation
* Corporate transportation providers

---

* Professional
* Trustworthy
* Modern
* Corporate

# Colors

Primary colors:

* Navy Blue
* White
* Red Accent

Logo:

* Navy "X"
* Red triangular accent

All design decisions should respect the existing brand identity.

---

# Language Requirements

Supported languages:

* English
* Arabic

Requirements:

* Full RTL support
* Preserve RTL functionality
* Preserve language persistence
* No English flash when Arabic is selected
* Maintain visual parity between English and Arabic versions

Always verify:

* Desktop English
* Desktop Arabic
* Mobile English
* Mobile Arabic

before considering work complete.

---

# Technical Rules

Preserve:

* Existing language toggle
* Existing RTL support
* Existing local storage persistence
* Existing quote form draft saving
* Existing contact form draft saving
* Existing navigation functionality

Do not remove working functionality unless explicitly requested.

---

# Design Rules

Use:

* Real photography whenever possible
* Premium transportation imagery
* Professional iconography
* Smooth animations
* Responsive layouts

Do not use:

* Low-poly graphics
* Placeholder illustrations
* Cartoon artwork
* Abstract vehicle simulations
* CSS-generated vehicle models
* Three.js vehicle demos unless specifically requested

For vehicle showcases:

* Prefer real vehicle photography
* Use executive sedans
* Use premium SUVs
* Use professional passenger vans

The website should communicate transportation services, not frontend engineering skills.

---

# Responsiveness

Every change must be tested for:

* Desktop
* Tablet
* Mobile

Avoid:

* Layout shifts
* Overflow issues
* RTL spacing issues
* Broken navigation
* Broken forms

# Workflow

Before making major changes:

1. Understand existing implementation.
2. Preserve working functionality.
3. Make changes incrementally.
4. Verify desktop and mobile.
5. Verify English and Arabic.
6. Verify accessibility.
7. Capture screenshots when appropriate.

Never sacrifice functionality for aesthetics.

The final goal is a premium transportation website that appears trustworthy enough for a customer to confidently request a quote.
